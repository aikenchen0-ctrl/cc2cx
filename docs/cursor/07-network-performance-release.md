# 07 网络优化与发布验收

## 目标

在真实 Cursor 流稳定后，测量并优化直连、区域入口、H1.1/H2 和流式体验。

## 前置

- 前 6 个阶段退出门全部通过。
- 已有可重复真实流式和取消路径。

## 实施

1. 对同一模型、同一合成请求、同一时间窗口做 A/B。
2. 采集 DNS/TCP/TLS/TTFB/TTFT、token interval、断流率、取消耗时和成功率。
3. 比较直连与区域入口、H1.1 与 H2。
4. 动态流默认不走未经验证的 CDN；选路保持会话粘性。

## 退出门

- 结果保存为聚合中位数、p95 和失败率。
- 只有 A/B 数据支持时，才允许宣称更快或更稳定。
- 发布包包含回滚、诊断和 CA 撤销说明。
