# cc-launch 品牌 Logo 接入设计

## 目标

使用用户提供的黑底白色几何 Logo 作为 cc-launch 的统一品牌资产，并同步到桌面应用图标、应用内品牌位、关于页面和浏览器页签。

## 资产策略

- 以 `src/assets/icons/app-icon.png` 作为唯一前端与打包源资产。
- 使用 Tauri 图标生成器生成 Windows、macOS、AppX、ICO、ICNS 和其他平台尺寸。
- 保留黑底白色图形，应用内使用固定黑色徽标容器保证浅色主题下的对比度。

## 界面策略

- 顶部主品牌位显示 Logo 和 `cc-launch` 文字。
- 窄屏隐藏文字，仅保留固定尺寸 Logo，避免与项目选择器和工具栏重叠。
- 关于页面复用同一 Logo 源资产，避免品牌图形分叉。
- 页面标题和 Tauri 窗口标题统一为 `cc-launch`。

## 验证

- 检查桌面和移动视口截图。
- 验证 Logo 资源可被 Vite 打包。
- 验证品牌组件和应用集成测试。
- 重新生成 Windows 安装包并检查产物图标和版本信息。
