# Agent 安装进度与首启引导设计

## 目标

应用安装完成后首次打开即进入 Agent 安装页面，用户可以在同一页面看到 Node.js 和各 Agent 的安装阶段、百分比、失败信息与重新检测结果。

## 交互状态

- 启动扫描完成且存在缺失 Agent 时自动打开安装页面。
- 页面顶部持续显示三步引导：环境检测、准备运行时、安装 Agent。
- 批量安装按 Node.js、目标 Agent 顺序执行，单项失败不阻塞后续项。
- 安装任务通过 `agent-install-progress` 事件推送阶段、状态、消息和可选百分比。
- 无法取得百分比时显示流动进度条，避免伪造精确数值。

## 视觉策略

- 使用深色科技感流水线面板、网格底纹、扫描线和阶段图标。
- 颜色语义固定：青色表示进行中，绿色表示完成，红色表示失败。
- 进度面板在桌面和移动视口保持可读，不遮挡安装列表和操作按钮。
- 尊重 `prefers-reduced-motion`，动画降级为静态状态。

## 验证

- 测试进度订阅 API、首启引导、Node.js 进度和 Agent 进度显示。
- 解析安装器输出中的百分比令牌，未提供百分比时使用不确定进度。
- 运行 TypeScript、Rust 检查和全量前端测试。
