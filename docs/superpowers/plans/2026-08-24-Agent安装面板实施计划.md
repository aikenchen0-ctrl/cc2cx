# Agent 安装面板 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 CC Switch 中提供全部受管 Agent 的安装状态列表、安装确认面板和可诊断的执行控制台。

**Architecture:** 扩展现有 Rust 工具生命周期服务，使其对 9 个 `AppType` 返回统一安装计划和实际探测状态。React 工具栏打开新面板，面板使用 Tauri API 获取计划、订阅执行日志并在结束后重新探测。

**Tech Stack:** Tauri 2、Rust、React 18、TypeScript、Vitest。
