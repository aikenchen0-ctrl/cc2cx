# cc2cx v3.20.2

本版本完善 Agent 安装体验，并增加旧 CC Switch 的安全迁移入口。

## Agent 安装

- 支持后台安装，关闭安装确认页后继续配置 API、Key 和其他设置。
- 主窗口右下角显示悬浮安装进度。
- 每个 Agent 安装完成后显示中英双语使用说明和一键打开按钮。
- 安装阶段和进度阶段补充中英双语显示。

## CC Switch 迁移

- 只读检测旧 CC Switch 数据目录和常见安装路径。
- 支持导入用户选择的 CC Switch SQL 导出文件。
- 导入前复用临时数据库校验和自动备份。
- 默认保留旧数据，不复制 OAuth 登录态，不直接删除旧应用。
- 提供平台卸载入口，卸载前应退出旧 CC Switch，避免两个程序同时写入 Agent 配置。

## Windows 排查

- 当前 Windows 包为 x64，下载时请确认系统架构。
- 未签名包可能触发 SmartScreen 或安全软件提示。
- 若出现“此应用无法在你的电脑上运行”，请检查实际文件路径、快捷方式目标、WebView2、系统架构和事件查看器。

本版本安装包未签名，首次启动可能需要系统安全确认。
