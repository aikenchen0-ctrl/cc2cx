# cc2cx v3.20.1

本版本修复 macOS Agent 安装完成但应用不可见、应用包误判和权限失败缺少引导的问题。

## 主要修复

- Codex UI 和 WorkBuddy 优先安装到 `/Applications`，无写入权限时回退到 `~/Applications`。
- 仅在应用包包含 `Contents/Info.plist` 和 `Contents/MacOS` 可执行文件时标记为已安装。
- Agent 安装页显示实际安装路径。
- 权限被拒绝时显示 Finder 权限检查、退出旧应用和重试指引。
- 启动时直接打开已检测到的应用路径，避免启动另一份旧副本。

## 支持平台

- Windows x64：NSIS、MSI
- macOS arm64：Apple Silicon DMG
- macOS x64：Intel DMG

本版本安装包未签名，macOS 首次启动可能需要在“系统设置 -> 隐私与安全性”中允许。
