# cc2cx v3.20.5

本版本修复 Windows WorkBuddy 签名校验、旧 CC Switch 卸载入口和 WSL Agent 启动环境。

- WorkBuddy 校验强制调用系统 Windows PowerShell 5.1，避免安全模块加载失败导致有效签名被误判。
- 发现旧 CC Switch 卸载程序或快捷方式时优先启动它，找不到时才打开 Windows 系统卸载页。
- Windows 检测到 CLI 配置位于 WSL 时，打开对应 WSL 发行版执行 Agent 命令。
- 旧 CC Switch 数据、API Key、OAuth、MCP、Skills 和备份默认保留。
